# character_viewer

マイク音声に超低遅延で反応して、透過背景のイラストを切り替える OBS 用キャラクター表示ツール（PNGTuber 型）。

## 目標

- 発話を検出してから絵が切り替わるまで **約 10〜40ms**
- 透過背景のまま OBS の配信・録画画面に重ねられる
- 作るのも使い続けるのも **完全無料**（OSS のみ、サーバー不要、すべてローカルで動作）
- 単純な画像切り替えから始め、段階的に機能を追加していく

## 構成（予定）

```
[コンデンサーマイク] → [オーディオIF] → PC
        │
        ▼
┌───────────────────────────┐      WebSocket (localhost)     ┌──────────────────────────┐
│ 音声エンジン (Rust)        │ ─────────────────────────────▶ │ 描画 (OBS ブラウザソース) │
│  WASAPI 共有モード・小バッファ │   状態イベント (数十バイト)      │  TypeScript + PixiJS     │
│  音量判定 + ヒステリシス     │                                 │  透過 PNG を切り替え表示  │
│  VAD (誤検出の抑制)          │                                 └──────────────────────────┘
│  状態遷移                   │
└───────────────────────────┘
```

| 層 | 技術 |
|---|---|
| アプリ本体 | Rust + Tauri 2 |
| 音声入力 | `cpal` / `wasapi` |
| 発話判定 | 自前 DSP（RMS + ヒステリシス + 保持時間）、補助に WebRTC VAD / Silero VAD |
| 通信 | `axum` + WebSocket |
| 描画 | TypeScript + Vite + PixiJS v8 |
| OBS 連携 | ブラウザソース、カスタムブラウザドック、obs-websocket v5 |
| イラスト | Krita（レイヤーごとに透過 PNG で書き出し） |

## ロードマップ

- [ ] **Step 1**: 音声エンジンの試作。マイクの音量を測り、発話中 / 無音を判定する
- [ ] **Step 2**: 描画側の試作。仮画像で「待機 / 発話 / 長い無言」を切り替える
- [ ] **Step 3**: OBS に組み込み、遅延を測定してしきい値を調整する
- [ ] **Step 4**: 設定画面（デバイス選択、しきい値、無言の秒数）と画像の即時反映
- [ ] **Step 5**: 口パク・まばたき・揺れなどの動き（パーツ分けした素材を使う）
- [ ] **Step 6**: 拡張（母音リップシンク、叫び差分、シーン連動、ホットキーでの表情切り替え）

## 状態遷移（Step 2 時点）

```
         声を検出（即座に）
 [待機] ─────────────────▶ [発話] ◀── どの状態からも即座に戻る
   ▲                         │
   └── 無音が 0.3 秒続く ─────┘
   │
   └─ 無音 N 秒 ▶ [放置] ▶ さらに M 秒 ▶ [寝落ち]
```

## イラスト素材のルール

- すべての差分を **同じキャンバスサイズ・同じ位置** で書き出す
- 透過 PNG で、表示サイズの 1.5〜2 倍の解像度にする
- フチや影はイラストには入れず、描画側で付ける
